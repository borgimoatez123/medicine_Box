SECTION 4  — API CONTRACT (Flutter → Backend)
================================================================================
Base URL: const String.fromEnvironment("API_BASE_URL",
                                      defaultValue:
                                      "http://192.168.1.170:3000/api")
Client : single instance ApiClient(http.Client + AuthStorage Bearer JWT
         injection + 20s timeout + UTF-8 JSON decode + existing 401 handler).
         Do NOT duplicate with a second client for new endpoints.

Endpoint                                        Flutter Layer call site
────────────────────────────────────────────────────────────────────────
GET /api/patients?page=1&limit=500
  → listMyPatients(limit:) → PatientPageResult.items
  Used by NotificationController to rebuild reminders
  and PatientDetailsScreen.

GET /api/medicine-boxes/{mbid}/sensors
  → SmartBoxRepository.getMedicineBoxSensors(mbid)
  → SmartBoxService.loadSensorState(mbid)
  → SmartBoxController.loadSensorStateForBox(mbid)
  → BoxScreen _SensorsSection rebuild via AnimatedBuilder
  (TEST #7 aggregate endpoint).

GET /api/drawers/{did}/sensors
  → SmartBoxRepository.getDrawerSensors(did)
  → SmartBoxService.loadDrawerSensorState(did)
  → SmartBoxController.loadDrawerSensorState(did)
    * side effect: upserts drawer into _sensorStateByBox[medicineBoxId].
  → DrawerAssignmentScreen _DrawerSensorSection rebuild
  (TEST #8 single drawer endpoint).

POST /api/drawers/{did}/open
  body: {}  |  {"reason":"Manual open by user"}
  → SmartBoxRepository.openDrawer(did, reason:)
     (via private _sendDrawerCommand helper)
  → SmartBoxService.openDrawer
  → SmartBoxController.openDrawer
    * guards double submit via Set<String> _sendingDrawerCommands
    * stores Map _lastCommandByDrawer and global lastCommand* fields.
  → DrawerAssignmentScreen _openDrawer sets feedback banner + SnackBar GREEN.
  (TEST #9 Open).

POST /api/drawers/{did}/close
  body: {}  |  {"reason":"Manual close by user"}
  → SmartBoxRepository.closeDrawer(did, reason:)
  → SmartBoxService.closeDrawer
  → SmartBoxController.closeDrawer
  → UI side: _confirmCloseDrawer dialog required, confirmed == true check
    before POST.
  → Feedback banner GREEN + SnackBar(textPrimary bg) after success.
  (TEST #9 Close).

Explicit FORBIDDEN endpoints (NEVER called by Flutter app):
  * GET  /api/devices/{deviceId}/commands    (Pi polling only).
  * POST /api/drawer-commands/{cmdId}/result (Pi writes result only).
  Reason: backend architecture = Edge (Raspberry Pi) executes command; the
  Flutter mobile app is a command CREATOR only. The mobile app must NOT try
  to spoof results.

401 / 404 / 400 / timeout / socket error mapping table lives at
§ 2.5 State-B, § 2.6.1 errors, § 2.6.2 command errors.
All error cards use user-friendly strings. Dio stack traces / Prisma / SQL
strings NEVER reach the UI.
